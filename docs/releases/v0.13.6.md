# gpuicn v0.13.6

A context menu with nothing to offer no longer opens. There are no API changes.
The runtime pins are unchanged: GPUI Kit 0.10.0 on `gpui-pre` 0.3.12, and
gpui-icons 0.7.0.

## Fixed

- **Menu, Context Menu:** a menu with no entries stays closed. An app that
  fills one shared context menu per row, as a sidebar does, used to show an
  empty sliver of a panel when the press landed where it had set no entries,
  such as a section heading. `MenuState::open_at` and `open` now do nothing
  while the menu is empty.
