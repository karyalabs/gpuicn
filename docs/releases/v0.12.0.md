# gpuicn v0.12.0

Three components for desktop apps that browse files and history: Tree, Diff
and Commit graph. They were built for Bonsai, a Git client, but none of them
knows about Git. There are no breaking changes. The runtime pins are
unchanged: GPUI Kit 0.9.1 on `gpui-pre` 0.3.12, and gpui-icons 0.7.0.

## Added

- **Tree** (`gpuicn add tree`): a virtualized hierarchy built on Virtual
  List.
  - Disclosure chevrons, with Left and Right to fold and move between
    parents and children.
  - Typeahead, and single or multiple selection.
  - Children loaded by the caller. A folder marked `TreeChildren::Unloaded`
    asks for its children with `TreeEvent::LoadChildren` when it opens, and
    shows a loading or retryable failed row until they arrive.
- **Diff** (`gpuicn add diff`): GPUI Kit's patch viewer with Nova defaults.
  - Unified or side-by-side layout, syntax highlighting, and virtualized rows.
  - Drag across line numbers to select lines. An action strip then offers the
    caller's `DiffAction`s, such as "Stage lines", and reports a `DiffIntent`
    with the file and line range.
  - File actions in every file header.
  - `read_only` for commit and review diffs.
- **Commit graph** (`gpuicn add commit_graph`): a history list on Virtual
  List with a lane graph column and ref labels.
  - The caller supplies each row's node lane and the edges entering and
    leaving the row. Each visible row paints only its own slice, so the graph
    stays aligned through scrolling and refreshes.
  - Node kinds differ by shape, not by color alone.
  - Lanes past `max_lanes` are clamped, with a marker.
  - Lane colors are eight hues derived from the theme's `info` color.

## Notes

- The Commit graph catalog page includes a compact lane assigner over a
  synthetic history of 2,000 commits, which you can copy as a starting point.
- macOS pointer and VoiceOver passes for the three components are still to
  be recorded; see each component's parity notes.
