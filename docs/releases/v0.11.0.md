# gpuicn v0.11.0

Moves gpuicn to GPUI Kit 0.9.1 on `gpui-pre` 0.3.12 (zed@d2a4fb6) and
gpui-icons 0.7.0. No gpuicn API changes; the minor version moves because the
runtime pins are exact, so apps must move their GPUI Kit, `gpui-pre-platform`
and gpui-icons pins together (`gpuicn update --to 0.11.0` does it).

## Changed

- **Runtime pins:** GPUI Kit `=0.9.1`, `gpui-pre-platform` `=0.3.12`,
  gpui-icons `=0.7.0`.

## Upstream highlights

- **Cached views track entities with nested scopes** (`gpui-pre`). Each
  `AnyView::cached` draw used to clone the frame's whole accessed-entity set
  to find what it touched; it now records into its own scope, so the cost of
  a cached view no longer grows with everything drawn before it. Cached views
  and `deferred` elements also keep the entities they read during paint and
  in deferred draws, so they re-render when those entities change.
- **`list()` respects horizontal padding and borders** (`gpui-pre`). Items are
  laid out inside the list's padding and border, and cached item heights are
  invalidated when those insets change. A list that relied on items spanning
  its full width despite padding now lays out narrower.
- **`anchored().attach(target, corner)`** places a popup against a target's
  corner and flips to the other side when it doesn't fit (`gpui-pre`).
- **Scrolling:** a smooth-scrolling mouse no longer bounces at the edge, and
  nested horizontal scrollers with nothing to scroll hand vertical swipes to
  the parent list (GPUI Kit).
- **Markdown:** clickable task-list checkboxes, link tooltips, and inline
  images hold a placeholder size until they load (GPUI Kit).
