# gpuicn v0.10.4

Markdown that reads like Mattermost, for karyalabs/matty's markdown review.
No breaking changes; the runtime pins are unchanged: GPUI Kit 0.9.0 on
`gpui-pre` 0.3.11 and gpui-icons 0.6.0.

## Changed

- **Tables are as wide as their content.** A table no longer stretches
  across the whole view with evenly spread columns: each column fits its
  widest cell, the header row is bold, and every cell has a rule. A table
  wider than the view shrinks its columns and wraps their text.
- **Headings sit closer to their section.** The gap above a heading is about
  a third of its size instead of up to one and a half times it, and the
  sizes step up a little more from the body (h1 1.6×, h2 1.36×, h3 1.18×).
- **Quoted text is at full strength.** A quote keeps its left rule and no
  longer fades its text.
- **Code blocks are slimmer**: 10px above and below the code instead of 12.

## Added

- `MarkdownBlocks`, the plugin that draws tables and headings, and
  `markdown_with(id, source, blocks, cx)`. `MarkdownBlocks::inline` renders
  a cell or heading's text with the application's own Markdown view, so
  links, mentions and emoji in them behave like the rest of the message.
  `markdown` uses plain views.
