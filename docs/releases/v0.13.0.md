# gpuicn v0.13.0

Moves gpuicn to GPUI Kit 0.10.0. GPUI Kit stays on `gpui-pre` 0.3.12
(zed@d2a4fb6), and gpui-icons stays at 0.7.0. There are no gpuicn API
changes; the minor version moves because the runtime pins are exact, so apps
must move their GPUI Kit pin with gpuicn (`gpuicn update --to 0.13.0` does it).
`gpui-pre-platform` stays at `=0.3.12`.

## Changed

- **Runtime pins:** GPUI Kit `=0.10.0` (was `=0.9.1`). `gpui-pre-platform`
  `=0.3.12` and gpui-icons `=0.7.0` are unchanged.
- **Theme:** GPUI Kit's new `list_highlight_foreground` color, used when an
  app turns on query-match highlighting in Select, Combobox or Command,
  follows the theme's `primary`.

## Fixed

- **Tabs keep automatic activation.** GPUI Kit 0.10's base `Tabs` adds its
  own roving focus that moves with the arrow keys without selecting (ARIA
  manual activation), and its tabs take over the focus handle gpuicn gave
  them. gpuicn's Tabs now draws its own tab list, so Left, Right, Home and End
  still select the tab they move to, as in shadcn, and skip disabled tabs.

## Upstream highlights

From GPUI Kit 0.10.0, the parts gpuicn's components and apps built on them
pick up without code changes:

- **Text input:** the caret moves and deletes by grapheme cluster, so emoji
  with modifiers and combining marks are one step; a long single-line paste
  reveals the caret; the secondary Enter binding no longer inserts a newline in a
  Textarea; auto-grow textareas no longer scroll at fractional scales; the
  IME candidate window stays on the composing row of a multi-line input.
- **Markdown:** white space folds the way HTML draws it, HTML `<pre>` is a
  code block, a paragraph of several images lays out inline, list numbering
  after a nested list is correct, and `TextView::link` can replace or drop
  links.
- **Text selection:** a triple click beside a line selects it, a press on a
  control that acts on the selection keeps it, and drag auto-scroll starts at
  an edge that hides text.
- **Tooltips:** long text wraps within `max_w`; one tooltip shows when a
  component tooltip sits inside a native `.tooltip()`; tooltip requests can
  set an anchor offset.
- **Buttons:** a disabled base Button ignores hover and active styles, a
  right or middle press no longer focuses a Button, and a loading button
  without an icon shows a spinner.
- **Accessibility:** labels, single-line and multi-line inputs expose their
  text to screen readers, and disabled inputs report as disabled.
- **Attachments:** GIF previews animate instead of freezing on the first
  frame.
- **Layout and motion:** a global right-to-left layout direction in
  `gpui-base`, and an explicit reduced-motion preference.
- **Tables:** `TableRow::id` keeps a row's identity when rows reorder,
  `TableRow::hover`, `scrollbar_mode`, and a striped table that doesn't fill
  its area no longer redraws every frame.
- **Other components:** `Checkbox` indeterminate state, `SidebarGroup`
  suffix actions, roving keyboard navigation in Tabs, a `list.highlight.foreground`
  theme color, `MessageScroller::scroll_to_offset`, and a Japanese locale.

GPUI Kit's own breaking changes in 0.10.0 (`TextareaMode::Extras`, the
`text_gutter_margin` → `text_origin_offset` rename, and `IntoElement` impls
under the optional `gpui-fast` backend) don't touch gpuicn's API.
