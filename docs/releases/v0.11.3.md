# gpuicn v0.11.3

One addition to the passive `HoverPopover` of 0.11.2, for karyalabs/matty's
sidebar peek card: no preview pops up over rows while a menu is open or a
channel is being dragged. No breaking changes; the runtime pins are
unchanged: GPUI Kit 0.9.1 on `gpui-pre` 0.3.12 and gpui-icons 0.7.0.

## Added

- **`HoverPopover::suppress_hover_when(f)`** keeps hover from opening the
  popup while `f` says so, such as while a menu is open or something is
  being dragged: resting the pointer starts no timer, and a pending one
  opens nothing. It is asked when the pointer moves and again when the
  delay ends, so it needs no redraw. An open popup stays open.
