# gpuicn v0.11.2

A passive mode for `HoverPopover`, for karyalabs/matty's sidebar peek card:
resting the pointer on an unread channel previews its newest posts while a
click still opens the channel. No breaking changes; the runtime pins are
unchanged: GPUI Kit 0.9.1 on `gpui-pre` 0.3.12 and gpui-icons 0.7.0.

## Added

- **`HoverPopover::passive()`** wraps the trigger as it is instead of making
  it a button, for a row that already has its own click and focus. Hover
  opens the popup after the delay as before; clicks reach the row; Escape
  closes it while focus is in the row or the popup.
- **`HoverPopover::open_requested(bool)`** opens the popup in that frame as
  a click would, moving focus into it, so a row's owner can open it from the
  keyboard (Space on a focused row). Closing gives focus back to whatever
  held it before.
