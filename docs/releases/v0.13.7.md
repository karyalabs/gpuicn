# gpuicn v0.13.7

Attachments can open a context menu. The runtime pins are unchanged: GPUI Kit
0.10.0 on `gpui-pre` 0.3.12, and gpui-icons 0.7.0.

## Added

- **Attachment:** `on_secondary_click` runs on a right-click with the press,
  so an app can open a menu at the pointer, such as Download or Copy link for
  a file in a message. Focus stays where the handler puts it.
