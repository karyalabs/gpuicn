# gpuicn v0.13.1

Diff gains a button beside each hunk and can hide its file headers. There are
no breaking changes. The runtime pins are unchanged: GPUI Kit 0.10.0 on
`gpui-pre` 0.3.12, and gpui-icons 0.7.0.

## Why

Bonsai's diff pane stages and unstages whole hunks with one click, the way
most Git clients do. Before this, a hunk could only be staged by selecting
its lines first. When the pane shows one file, its own toolbar already names
the file, so the file header inside the diff repeated it.

## Added

- **`DiffView::hunk_action(action, hunks)`** puts a small icon button in the
  gutter beside the first line of each hunk range you pass. The action's
  label is the button's tooltip and accessible name. A click reports a
  `DiffIntent` whose `range` is that hunk, so the same handler that applies
  selected lines applies the hunk. It is hidden in read-only mode.
- **`DiffView::header_visible(bool)`** hides the file headers, for a view of
  one file whose path is shown elsewhere. Headers are shown by default.

Diff now depends on Tooltip as well as Button. `gpuicn add diff` installs it.
