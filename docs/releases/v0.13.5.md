# gpuicn v0.13.5

A new GIF Picker for chat composers. The runtime pins are unchanged: GPUI Kit
0.10.0 on `gpui-pre` 0.3.12, and gpui-icons 0.7.0.

## Added

- **GIF Picker:** a search field and a two-column masonry grid of GIFs that
  loads more as it scrolls, as the GIF tab of Mattermost's emoji picker does.
  The application owns the GIF service: it answers
  `GifPickerEvent::Search` with `set_gifs` and `LoadMore` with
  `extend_gifs`, and supplies each preview image. The picker is as wide and
  as tall as the Emoji Picker, so the two can share a popover under tabs.
  The arrow keys move through the grid while the search field keeps focus,
  Enter picks, and Escape clears the search or closes
  (karyalabs/matty#958).
