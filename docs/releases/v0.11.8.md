# gpuicn v0.11.8

Link previews laid out as Mattermost's webapp, found in karyalabs/matty, where
a preview without a site name opened with an empty row that held only the
collapse chevron. There are no API changes. The runtime pins are unchanged:
GPUI Kit 0.9.1 on `gpui-pre` 0.3.12, and gpui-icons 0.7.0.

## Changed

- **`LinkPreview`'s collapse toggle** is a round 24px chevron over the large
  image's top-left corner, named "Hide image preview". Once hidden, a "Show
  image preview" button takes the image's place. Only a site name or the
  remove button add a row above the title now.
- **Large images keep their own size**, scaled down (never up) to fit
  392 × 240, instead of filling the card. The card fills its container up to
  700px.
- **Text** follows the webapp too: the title on one line, the description
  clamped to two.
- **Thumbnails**: an image narrower than 4:3 (was 6:5) shows as an 80px
  thumbnail beside the text. A thumbnail always shows and has no toggle, as
  in the webapp.
