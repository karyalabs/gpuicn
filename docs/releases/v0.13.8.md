# gpuicn v0.13.8

An attachment's right-click now works under a row that has its own context
menu. The runtime pins are unchanged: GPUI Kit 0.10.0 on `gpui-pre` 0.3.12,
and gpui-icons 0.7.0.

## Changed

- **Attachment:** `on_secondary_click` runs on release, as a click does, and
  its handler now takes the `MouseUpEvent`. The release stops at the
  attachment, so a message row that opens its own menu on release no longer
  replaces the attachment's menu. It came in 0.13.7, one release ago.
