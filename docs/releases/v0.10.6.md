# gpuicn v0.10.6

A lighter reactions row, for karyalabs/matty's performance work
(matty#796). No breaking changes; the runtime pins are unchanged: GPUI Kit
0.9.0 on `gpui-pre` 0.3.11 and gpui-icons 0.6.0.

## Changed

- **`Message`'s add-reaction button shows while the row is hovered or
  selected**, as in Mattermost, instead of on every row with reactions.
  Rows the pointer is not on lay out only their chips. A row without an
  action bar (no `actions`/`actions_with`) has no hover tracking and keeps
  the button showing.
- **Reaction chips format no id strings per frame.** Each chip's wrapper is
  named by the message and the emoji, and its button by a fixed name inside
  it.
