# gpuicn v0.11.6

A fix for how a message's header lines up, found in karyalabs/matty. There
are no breaking changes. The runtime pins are unchanged: GPUI Kit 0.9.1 on
`gpui-pre` 0.3.12, and gpui-icons 0.7.0.

## Fixed

- **A message header's name, time and markers line up.** The header row
  used `items_baseline`, but GPUI reports no text baselines, so the boxes
  lined up by their tops: the 12 px time sat about 3 px above the 14 px
  name, and a marker added with `header_child` (an icon and "Saved", say)
  sat between the two. The row now centres its items, which lines text of
  any size up to within a pixel and centres an icon on it. An embed's
  author and time get the same fix.

## Also in this release

- Registry items carry a `meta` with the release each component first
  shipped in and its catalog group, which the site and the gallery read
  for their "New" badge and groups.
- `loop_phase` steps on the executor's clock, so looping animations follow
  simulated time in tests.
