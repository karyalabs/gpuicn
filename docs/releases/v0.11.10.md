# gpuicn v0.11.10

Tooltips that sit on what they describe, and roomier menu rows. Both came from
Matty: a status emoji's tooltip opened below and to the right of the pointer,
and the server switcher's two-line rows were pressed together. There are no
breaking changes. The runtime pins are unchanged: GPUI Kit 0.9.1 on `gpui-pre`
0.3.12, and gpui-icons 0.7.0.

## Added

- **`AnchoredTooltip::anchored_tooltip`** shows a hover tooltip centered above
  any element, with an arrow pointing at it. It flips below when there is no
  room above and stays 8px inside the window. A tooltip on an element inside
  another's (a status emoji in a row) wins while the pointer is over it.
  Pressing or scrolling hides it.

```rust
use gpuicn::tooltip::{AnchoredTooltip as _, text_tooltip};

div()
    .id("status")
    .anchored_tooltip(move |_, cx| text_tooltip("In a meeting".into(), cx))
    .child(emoji)
```

## Changed

- Every gpuicn tooltip that used GPUI's native `.tooltip(...)` now uses
  `anchored_tooltip`: the sidebar's collapsed items and label suffixes, message
  times and reactions, avatar groups and virtual list rows.
- Menu rows with a description grow to fit their two lines with 6px above and
  below, keep 2px between the name and the description, and draw the
  description at normal weight. A leading element such as an avatar tile sits
  10px from the text. Separators have 6px above and below.
