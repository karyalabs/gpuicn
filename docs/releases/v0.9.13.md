# gpuicn v0.9.13

Fixes from the gpuicn cleanup review (#160). The runtime pins are unchanged:
GPUI Kit 0.9.0 on `gpui-pre` 0.3.11 and gpui-icons 0.6.0.

## Fixed

- `ShowMore` and the quoted-post clamp show their Show more toggle inside a
  cached view. They measured in prepaint and called `window.refresh()`,
  which GPUI ignores during a frame, so an app that caches its panes kept a
  long message clipped with no toggle (#161).
- Sortable drag targets, the Drawer swipe, ScrollArea keyboard scrolling and
  VirtualList keys repaint only the view that renders them instead of
  refreshing the whole window, so an app's other cached views are reused
  (#163).
- `Calendar` takes Escape (and emits `CalendarEvent::Cancel`) ahead of an
  app's own Escape shortcut, and Escape cancels a `Resizable` drag the same
  way; both now use the `Dismiss` action like the dialogs (#165).
- The message list's "N new messages" jump label is a translatable
  `UiText::NewMessages` (#166).
- Release packaging retries Apple's stapler when the ticket download drops,
  which failed the 0.9.10 and 0.9.11 releases after notarization had passed
  (#162).

## Added

- `dialog_with` and `alert_dialog_with` build the popup only while the
  dialog is open, so a closed dialog costs only its focus bookkeeping
  (#164). `dialog` and `alert_dialog` still take a built popup.
