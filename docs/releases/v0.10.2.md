# gpuicn v0.10.2

A small addition for karyalabs/matty#731. No breaking changes; the runtime
pins are unchanged: GPUI Kit 0.9.0 on `gpui-pre` 0.3.11 and gpui-icons 0.6.0.

## Added

- **`Sidebar::surface(true)`** draws the navigation on the page's `muted`
  surface with `foreground` text, and **`SidebarItem::surface(true)`** gives
  its rows the page's colors (`accent` when hovered or selected, `ring` for
  focus). Use it for a section list beside a page, such as a settings
  window, so it does not read as a second app sidebar when a theme paints
  the sidebar a strong color.

  ```rust
  Sidebar::new("sections", "Sections")
      .surface(true)
      .child(SidebarItem::new("general", "General").surface(true).selected(true))
  ```
