# gpuicn v0.10.3

Fixes for karyalabs/matty#748 (paper-cuts found in Matty beta.11). No
breaking changes; the runtime pins are unchanged: GPUI Kit 0.9.0 on
`gpui-pre` 0.3.11 and gpui-icons 0.6.0.

## Fixed

- **A press on a control is the control's.** `Button`, the "Show more"
  toggle, embed and attachment cards, image frames and mention chips claim
  their left press (`primitives::press`). Pressing one no longer starts a
  window text selection (dragging off a reaction chip selected text), and a
  `Message` row with `on_click` leaves the click to the control, so copying
  a code block or expanding a long message no longer opens the thread.
- **Tooltips follow the theme.** `surface::tooltip` is now the popover
  surface (popover colors, border, `shadow-md`, medium radius) instead of
  inverted colors, so tooltips are dark in dark mode and light in light mode.
- **A selected `SidebarItem` keeps its colors on hover**, including colors
  an app sets on it.

## Added

- `message::emoji_tooltip(emoji, image, text, hint, cx)`: the reaction
  chip's tooltip (large emoji over bold text and a muted hint) for anything
  an emoji stands for, such as a custom status.
- `SidebarItem::label_suffix_tooltip_view` shows a view, such as
  `emoji_tooltip`, as the suffix's tooltip.
- `primitives::press::{claim, claim_now, claimed, reset}` for controls of
  your own inside a clickable container.
