# gpuicn v0.11.5

Changes for themes whose sidebar is not the page's light or dark, such as a
navy sidebar beside a white page, and for themes whose `primary` is a fill
that does not read as text. They come from the theme rework in
karyalabs/matty. There are no breaking changes. The runtime pins are
unchanged: GPUI Kit 0.9.1 on `gpui-pre` 0.3.12, and gpui-icons 0.7.0.

## Added

- **`ButtonVariant::Sidebar` and `ToggleVariant::Sidebar`** are the ghost
  button and the toggle for a control that sits on the sidebar. They are
  clear at rest and hover in `sidebar_accent` with
  `sidebar_accent_foreground`. A ghost button hovers in the page's `muted`,
  which on a dark sidebar beside a light page is a pale box with pale text.
  `sidebar_menu_action` now uses the variant.
- **`ToggleGroup::segmented(true)`** draws the group as one segmented
  control: a muted track with a hairline, and the pressed option raised on
  it. A joined group marks the pressed option with the same fill a hovered
  option gets, so the choice was hard to see. `ControlColors::segment` is
  the raised fill.
- **`TitleBar::page(true)`** draws the bar in the page's muted colors, for a
  window with no sidebar under it, such as a settings window.

## Changed

- **Text is no longer drawn in `primary`.** A message's reacted count, the
  `Link` button, the collapsible trigger and the embed toggle used `primary`
  as a text color. `primary` is a fill: a pale accent that carries a dark
  label passes as a button and fails as text. They now use `link()`, which
  falls back to `primary` when a theme sets no link color, so a theme
  without one looks as before.
- **The title bar reads on any sidebar color.** `TitleBar` fills with
  `sidebar` and drew its content and window controls in the page's
  `foreground` and `muted_foreground`. It now uses `sidebar_foreground`,
  `sidebar_muted_foreground()`, `sidebar_border` and, for the hovered
  controls, `sidebar_accent`. `WindowControls` used on their own keep the
  page's colors.
- **The color picker's hue track is always vivid.** It was drawn at the
  picked color's lightness and chroma, so for a near-grey or a dark color
  the whole track was one grey. The chroma track is drawn at a mid
  lightness for the same reason.
