# gpuicn v0.11.9

Row actions that keyboard users can see, asked for in
[#187](https://github.com/karyalabs/gpuicn/issues/187). Matty's sidebar section
headers show their "+" and "⋯" only on hover, so a keyboard user on the header
never saw them. There are no breaking changes. The runtime pins are unchanged:
GPUI Kit 0.9.1 on `gpui-pre` 0.3.12, and gpui-icons 0.7.0.

## Added

- **`item::Reveal`** wraps row actions. They show while the row marked
  `.group(name)` is hovered, while keyboard focus is on one of them, and,
  with `Reveal::focus_within(&handle)`, while keyboard focus is anywhere inside
  the element that tracks `handle`. Hidden actions keep their place in layout,
  stay in the tab order and stay in the accessibility tree. A pointer click
  that leaves focus behind does not keep them shown.

```rust
div()
    .group("section")
    .track_focus(&header_focus)
    .child(trigger)
    .child(
        Reveal::new("section.actions", "section")
            .focus_within(&header_focus)
            .child(add_button)
            .child(options_button),
    )
```
