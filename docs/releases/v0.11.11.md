# gpuicn v0.11.11

Descenders stay on. A truncated label inside a button, a menu row, a tab or a
toolbar button lost the bottom of every g, p and y, most visibly in Matty's
server switcher. There are no breaking changes. The runtime pins are
unchanged: GPUI Kit 0.9.1 on `gpui-pre` 0.3.12, and gpui-icons 0.7.0.

## Why it happened

GPUI Kit's base `Button`, `Toggle` and `Tab` set `line_height(relative(1.))`,
a line box exactly the font size. Glyphs reach further than that: Geist and
IBM Plex Sans need 1.3em from the top of an accent to the bottom of a g. GPUI
centers the glyphs in the box, so they spill a little above and below it,
which is harmless until something clips to the box. `truncate()` does, so
every truncated label inside one of those controls was cut off at the
baseline plus a pixel or two.

## Fixed

- Every gpuicn component built on a GPUI Kit base control sets its text's line
  height again: buttons (all sizes), menu rows and their descriptions, tabs,
  toolbar buttons, collapsible triggers and clickable items. Badges, key caps
  and tags, which set the same 1.0 line height themselves, use 16px.
- Controls with a fixed height look the same: the glyphs are centered in the
  taller box exactly where they were. A collapsible trigger keeps its 26px
  height with 3px of padding around a 20px line. A menu row with a description
  stays 42px tall, with the name and the description in 20px and 16px boxes.
- Dialog titles get the type scale's 24px line instead of 16px, so a dialog
  header is 8px taller.

## Added

- **`text::line_height(theme, size)`**: the type scale's line height for a
  size on the scale (14px gets 20px), otherwise 1.4 times the size, never less
  than **`text::INK`** (1.3em).
- **`text::control(element, theme, size)`** sets a text size and that line
  height together, for anything built on a GPUI Kit base control.

## Guarded

- `tests/descenders.rs` renders a truncated label inside each of these
  controls and fails when its box is shorter than its glyphs.
- The registry lint fails a component that builds on a GPUI Kit base control
  without setting a line height, and any `line_height` under 1.3 times the
  text size beside it.
