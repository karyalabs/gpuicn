# gpuicn v0.11.4

Message row fixes from a side-by-side comparison of karyalabs/matty with the
official Mattermost client. There are no breaking changes. The runtime pins
are unchanged: GPUI Kit 0.9.1 on `gpui-pre` 0.3.12, and gpui-icons 0.7.0.

## Added

- **`Message::footer(element)`** adds a line under the reactions, such as a
  thread's reply summary. Mattermost shows reactions above "3 replies", but
  a child passed to the body landed above the reactions.

## Changed

- **Clicking blank space in a message no longer starts a text selection.**
  Before, a press anywhere in the row (beside a short line, or between two
  blocks) anchored a selection at the nearest text. Any small movement
  before release then highlighted part of the message. Now only a press on
  text starts a selection. Shift-click still extends one, and the row's
  `on_click` still runs for a press on blank space.
- **Entity links read as links.** `EntityLinks` draws other people's
  mentions and channel links as plain link text with an underline on hover,
  as Mattermost does. Only a target that `highlight` matches, such as the
  reader's own mention, keeps the filled chip.
- **Link previews:** an empty `site_name` no longer leaves a blank row at
  the top of the card. A clickable title uses the theme's link color, not
  `primary`.
