# gpuicn v0.10.5

Loading indicators that cost almost nothing, for karyalabs/matty's
performance work (matty#792). No breaking changes; the runtime pins are
unchanged: GPUI Kit 0.9.0 on `gpui-pre` 0.3.11 and gpui-icons 0.6.0.

## Changed

- **`Spinner` and `Skeleton` step 12 times a second instead of every
  frame.** A spinner in a connection banner used to redraw its view 60 or
  120 times a second for as long as it showed. Both now move in steps on
  one clock shared by every loop, and a view holding several loops redraws
  once per step.
- **They pause in background windows.** While the window is inactive no
  step is scheduled; bringing the window forward redraws it and the loop
  carries on. Reduced motion still shows them still.

## Added

- `theme::loop_phase(period, window, cx)` and `LOOP_STEPS_PER_SECOND`, for
  other looping indicators that should behave the same way.
