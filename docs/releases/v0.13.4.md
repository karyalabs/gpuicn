# gpuicn v0.13.4

Escape closes an Alert Dialog, and a tab's context menu keeps the keyboard.
There are no API changes. The runtime pins are unchanged: GPUI Kit 0.10.0 on
`gpui-pre` 0.3.12, and gpui-icons 0.7.0.

## Fixed

- **Alert Dialog:** Escape cancels it, as in shadcn. The Kit host's own
  Escape binding was turned off so an app's Escape shortcut could not take
  the key first, but nothing replaced it, so Escape did nothing. It now goes
  through the same `Dismiss` route as Dialog. A press outside still does
  nothing, so an alert still needs an answer.
- **Tabs:** a tab's `on_secondary_click` handler can open a context menu that
  keeps focus. GPUI focused the tab on that same press after the handler ran,
  so the menu it opened ignored Escape, the arrows and Enter
  (karyalabs/matty#943).
