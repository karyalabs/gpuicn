# gpuicn v0.13.2

Dialogs can be wider. There are no breaking changes. The runtime pins are
unchanged: GPUI Kit 0.10.0 on `gpui-pre` 0.3.12, and gpui-icons 0.7.0.

## Why

Bonsai's Accounts, Settings and Purge sheets need more room than 384 px:
account cards, side-by-side settings rows and a file tree all wrap or clip at
that width. `dialog_popup` already returns a styled element, but the dialog
host capped its child at 384 px as well, so calling `.max_w(..)` on the popup
had no effect.

## Fixed

- **Dialog:** the host no longer caps the popup's width and centers it
  instead. `dialog_popup` keeps its 384 px default, so existing dialogs look
  the same; call `.max_w(px(560.))` on it for a wider sheet.
- **Command:** `command_dialog_popup` asked for 480 px but was held to
  384 px by the same cap. It now opens at 480 px.
